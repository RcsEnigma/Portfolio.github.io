Discover shared categories between words — for building NYT-style Connections puzzles.

One field: see every category each word could belong to. Add a second: cross-reference the two. Add more: every pair of fields gets checked, never all at once.

Fill in any of the 8 fields below (one candidate word/phrase per line) to steer generation — leave any blank and the algorithm picks freely for that spot. Each edge field represents BOTH non-corner cells on that side at once: on generate, the algorithm looks through the words you listed, picks one to determine the category, then finds a second word (from your list if another one fits, otherwise its own pick) for the other cell. Words you type that don't end up used are never placed anywhere else in the loop.

Rules & Plugins

Every rule is a plugin. Toggle any of them off, or add your own custom word-sets below.

Live word-association APIs

These call free, keyless APIs — Datamuse for synonyms, statistical associations, and collocations, and ConceptNet for structured relations like "used for" and "part of" — that aren't hardcoded anywhere. Results are cached locally for 24h. Requires an internet connection.

Custom word sets

Paste JSON of the shape {"Category Name": ["word1","word2",...]} to add your own permanent categories, or load a pack from a URL (works great with raw JSON files from dariusk/corpora on GitHub, using a raw.githubusercontent.com link).
